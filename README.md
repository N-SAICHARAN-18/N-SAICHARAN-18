### 👨‍💻 About Me

* 🎯 **Immediate Goal:** Placement preparation, sharpening algorithmic problem-solving, and becoming a well-grounded software engineer.
* 💡 **Learning Philosophy:** Fundamentals first, validated by working code and practical projects.
